Claude · MCP

Name a song and Claude builds the preset on your rig.

OpenRig speaks MCP, so Claude can look up the amp, cab and pedals used on the record, pick the closest gear in the catalog and save the preset while you keep playing.

Install in Claude Code
> /plugin marketplace add jpfaria/OpenRig-claude
> /plugin install claude-plugin@openrig
$ openrig --mcp

Six skills in one plugin: see them on GitHub.

Tone Builder

Researches the chain used on a song, maps it to the catalog and saves it as a new preset.

Plugin packager

Turns your .nam and IR files, or a tone3000.com pack, into an OpenRig plugin with its manifest.

MIDI Profile Builder

Writes the profile for your footswitch from a description or a MIDI capture.
