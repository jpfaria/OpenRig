Roadmap

Where it is.
Where it's going.

Everything below is public. Each line is an issue on GitHub you can read, comment on, or pick up.

Playing today

  • Chain editor with real knobs, drag to reorder
  • Five backends in one rig — native, NAM, LV2, VST3, IR
  • Capture packs turned into knobs automatically
  • Presets and scenes, switched without a gap
  • MIDI Learn and footswitch profiles
  • Looper, DI loop, metronome, tuner, spectrum, Tone Doctor
  • MCP server and the Claude skills
  • Several interfaces at once, insert loop for hardware
  • macOS build, signed and notarized

Next up

  • Linux and Windows builds
  • Setlist mode for the gig
  • A/B compare between two tones
  • Global tap tempo and expression pedal
  • Trim and reuse a recorded loop
  • Footswitch profile editor inside the app
  • Bass and keys rigs

Further out

  • Parallel routing and chain splits
  • Master mixer per stream
  • Node-graph chain editor
  • Backing tracks in the app
  • More native DSP modelled from papers
  • One-click plugin pack installer

Want something moved up the list? Open an issue.
